# blog.yuo.be

This repo contains the source for my personal blog,
[blog.yuo.be](https://blog.yuo.be).

The site was built using [Astro](https://astro.build).

## Building the site

To build the site:

1. Install [Node.js](https://nodejs.org/en/)
2. Install [pnpm](https://pnpm.io/installation)
3. Install [Python](https://www.python.org/)
4. Install [uv](https://docs.astral.sh/uv/getting-started/installation/)
5. Run `uv sync`
6. Activate the Python virtual environment by running
   `source .venv/bin/activate` (Linux) or `.venv\Scripts\activate` (Windows)
7. Run `pnpm install`
8. Run `pnpm run build`

[See the Astro documentation](https://docs.astro.build/en/) for more information
on using Astro.
